About the AI model

The Python API uses a weighted k-nearest-neighbors model. It compares each donor’s blood group, city, and activity time with similar records, then estimates availability from those neighbors.

The supplied list contains 27 demonstration records. The model is small and illustrative; it does not verify real-time availability, donor eligibility, or medical compatibility.
